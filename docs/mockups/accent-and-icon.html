Accent and icon

One fixed accent, teal or cyan, and an icon that uses it. Part 1 shows each candidate across the parts of the app the accent touches: logo, selected segment, focus ring, primary button, link text, page selection, thumbnail outlines and the mini map's view box. Each also sits beside a red markup, since drawings often carry red redlines. The numbers underneath are contrast ratios. Part 2 shows eleven icon ideas at Windows sizes, in Deep teal.

Part 1. Which teal or cyan

Text contrast is APCA (the WCAG 3 draft), shown as Lc: higher is easier to read, and about Lc 60 is the floor for short UI text like a button label. WCAG 2's older ratio, which this page used first, overrates dark text on mid-tone colours like these and was pointing the wrong way. Outlines, rings and the logo still use WCAG 2's 3:1 for non-text, since APCA has no settled rule for them yet. Each primary button shows both text colours so you can judge by eye. The last row, Split, uses one hue in two shades: bright in dark, deep in light.

Part 1b. Accent-coloured text, on Deep teal

Deep teal (#0d9488) is the accent. As text it only reaches Lc 36 on the dark theme's panels. (a) a text-only shade per theme: a lighter teal (#2dd4bf) in dark, a deeper one (#0f766e) in light, used for links only, as Windows 11 does. (b) no accent text at all: links in normal text, underlined. In both, the current zoom preset gets a tick (proposal D2) and the Properties path becomes normal text, since it isn't clickable. Buttons keep white text on Deep teal.

Light theme: which text shade

#0f766e scores well but reads as near-black at text size. Lighter shades, darkest first. The last is Deep teal itself, which would mean one teal for everything in the light theme. About Lc 60 is the usual floor for short text like these links.

Part 2. Icon ideas

Eleven ideas in Deep teal: the first four from before, then seven more (5 to 11). Each is shown at 256 px (Start menu, Explorer large icons), then 48, 32, 24 and 16 px (title bar, taskbar, Explorer details), on Windows' dark and light taskbars. The 16 px one is the hard test, and the title bar would use the same mark. These are concepts for picking a direction; the chosen one gets redrawn by hand at the small sizes. Tile or no tile is itself a choice: Windows 11's own icons mostly have no tile (ideas 2, 7 and 10 here), while a tile holds its shape better at 16 px.
